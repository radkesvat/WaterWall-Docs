# All Nodes

This page is a quick inventory of the public configurable WaterWall nodes found in the current source tree. Every node name links to its reference page for exact settings, supported modes, placement, and examples. For a guide organized by purpose, start with the [Introduction](../00-intro.mdx#available-node-families) or [Choosing Nodes](../01-getting-started/tutorial-part4.mdx). Custom builds can disable individual node types.

## Basic Reading Guide

- Listener and device nodes usually sit at the edge of a chain and create or receive traffic.
- Connector nodes usually sit at the outbound edge and connect to an external endpoint.
- Packet nodes carry raw IP packets or datagram-like packet buffers, not ordinary TCP byte streams.
- Bridge nodes cross between packet and stream models or between separate chain branches.
- Most `Client` / `Server` protocol pairs must be configured on opposite sides of the path.

## Public Configurable Nodes

| Node | Main use | Common placement |
|---|---|---|
| [APIServer](./APIServer.mdx) | Authenticated access to explicitly registered node operations, including authentication status and user management. | Terminal node after TcpListener, HttpServer or KcpServer. |
| [AuthenticationClient](./AuthenticationClient.mdx) | Maintains the authentication-control session and local users table for nodes that use its API. | Control-chain head leading to `AuthenticationServer`, often through `TcpConnector`. |
| [AuthenticationServer](./AuthenticationServer.mdx) | Terminal authentication-control backend that serves users and accepts client requests. | End of an `AuthenticationClient` control chain; it has no `next`. |
| [Bgp4Client](./Bgp4Client.mdx) | Client side of the BGP4-style tunnel pair. | Paired with `Bgp4Server`. |
| [Bgp4Server](./Bgp4Server.mdx) | Server side of the BGP4-style tunnel pair. | Paired with `Bgp4Client`. |
| [BlackHole](./BlackHole.mdx) | Terminal sink adapter that drops payload or rejects traffic for blocking and tests. | End of a policy/test chain. |
| [Bridge](./Bridge.mdx) | Connects two independent chain branches inside one config. | Usually used as a named pair/branch join. |
| [ConnectionFisherClient](./ConnectionFisherClient.mdx) | Opens or races multiple client-side paths and keeps the useful connection. | Paired with `ConnectionFisherServer`. |
| [ConnectionFisherServer](./ConnectionFisherServer.mdx) | Server side for ConnectionFisher paths. | Paired with `ConnectionFisherClient`. |
| [ConnectionStripeClient](./ConnectionStripeClient.mdx) | Stripes each application byte stream over 1–32 full-duplex transport connections. | Before a reliable transport path to `ConnectionStripeServer`, such as TLS/TCP or KCP/UDP. |
| [ConnectionStripeServer](./ConnectionStripeServer.mdx) | Reassembles each transport group into one ordered application stream. | After transport decoding, before the application-side path or destination connector. |
| [ConnectionToPackets](./ConnectionToPackets.mdx) | Opens a connection line as a userspace lwIP TCP/UDP flow and emits raw IPv4 packets. | Connection-to-packet bridge after a destination-setting node such as `Socks5Server`. |
| [Disturber](./Disturber.mdx) | Simulates loss, delay, or corruption for testing. | Test chains. |
| [DomainResolver](./DomainResolver.mdx) | Advanced support node that resolves `dest_ctx` domains before forwarding `Init`. | Usually created internally by connector/router/client nodes. |
| [EncryptionClient](./EncryptionClient.mdx) | Client-side AEAD framing/encryption. | Paired with `EncryptionServer`. |
| [EncryptionServer](./EncryptionServer.mdx) | Server-side AEAD framing/decryption. | Paired with `EncryptionClient`. |
| [EnetClient](./EnetClient.mdx) | Carries a reliable byte stream over a packet-preserving path using native ENet. | Paired with `EnetServer`. |
| [EnetServer](./EnetServer.mdx) | Reconstructs the reliable byte stream from native ENet connections. | Paired with `EnetClient`. |
| [FakeTcpHeaderClient](./FakeTcpHeaderClient.mdx) | Inserts fake TCP and a per-packet protocol byte into an existing IPv4 packet; removes them from replies. | Packet chains before RawSocket, paired with `FakeTcpHeaderServer`; TCP/UDP, ICMP and opaque IPv4 carriage. |
| [FakeTcpHeaderServer](./FakeTcpHeaderServer.mdx) | Removes fake TCP and its protocol byte from requests; inserts both into native replies. | After RawSocket and address restoration, before a suitable native packet consumer. |
| [GnsClient](./GnsClient.mdx) | Carries a reliable byte stream over a packet-preserving path using native GameNetworkingSockets. | Paired with `GnsServer`. |
| [GnsServer](./GnsServer.mdx) | Reconstructs the reliable byte stream from native GameNetworkingSockets connections. | Paired with `GnsClient`. |
| [HalfDuplexClient](./HalfDuplexClient.mdx) | Splits or coordinates half-duplex upload/download behavior. | Paired with `HalfDuplexServer`. |
| [HalfDuplexServer](./HalfDuplexServer.mdx) | Server side of the half-duplex tunnel pair. | Paired with `HalfDuplexClient`. |
| [HeaderClient](./HeaderClient.mdx) | Prepends a one-time WaterWall port header or IPv4 PROXY protocol header. | Paired with `HeaderServer` for WaterWall headers, HeaderServer PROXY source mode, or before a PROXY-aware backend. |
| [HeaderServer](./HeaderServer.mdx) | Consumes a WaterWall port header, reads IPv4 PROXY source fields, or applies a constant destination port. | Paired with `HeaderClient` or placed behind a trusted PROXY sender. |
| [HttpClient](./HttpClient.mdx) | Wraps payload in HTTP, HTTP/2, h2c, custom upgrade, split HTTP, or WebSocket client framing. | Before `TlsClient` for HTTPS, or before a transport node for cleartext HTTP. |
| [HttpServer](./HttpServer.mdx) | Parses HTTP/WebSocket server-side framing and forwards body payload. | After `TlsServer` for HTTPS, or after a listener for cleartext HTTP. |
| [HttpProxyClient](./HttpProxyClient.mdx) | Sends HTTP/1.1 CONNECT or one configured HTTP request through an upstream proxy. | `source -> HttpProxyClient -> optional TlsClient -> TcpConnector`; target settings identify the origin. |
| [HttpProxyServer](./HttpProxyServer.mdx) | Forwards HTTP/1.x proxy requests and CONNECT through its configured next chain. | `TcpListener -> HttpProxyServer -> outbound chain`; local users, AuthenticationClient, or explicit no-auth. |
| [IpManipulator](./IpManipulator.mdx) | Applies packet-level TCP/TLS/SNI manipulation tricks. | Packet chains. |
| [IpOverrider](./IpOverrider.mdx) | Rewrites source/destination IP or port fields in packet traffic. | Packet chains. |
| [JunkDatagramSender](./JunkDatagramSender.mdx) | Sends extra datagrams according to configured modules/policies. | Packet or UDP-oriented evasion/test paths. |
| [KcpClient](./KcpClient.mdx) | Carries a reliable byte stream over a packet-preserving path using KCP. | Paired with `KcpServer`. |
| [KcpServer](./KcpServer.mdx) | Reconstructs the reliable byte stream from KCP transport packets. | Paired with `KcpClient`. |
| [KeepAliveClient](./KeepAliveClient.mdx) | Sends keepalive/heartbeat data to detect broken paths. | Paired with `KeepAliveServer`. |
| [KeepAliveServer](./KeepAliveServer.mdx) | Server side of keepalive/heartbeat handling. | Paired with `KeepAliveClient`. |
| [LoggerTunnel](./LoggerTunnel.mdx) | Logs or dumps payload without modifying chain behavior. | Anywhere suitable for debugging. |
| [MuxClient](./MuxClient.mdx) | Multiplexes many logical lines over shared transport connections. | Paired with `MuxServer`. |
| [MuxServer](./MuxServer.mdx) | Demultiplexes logical lines from `MuxClient`. | Paired with `MuxClient`. |
| [ObfuscatorClient](./ObfuscatorClient.mdx) | Client-side lightweight payload obfuscation. | Paired with `ObfuscatorServer`. |
| [ObfuscatorServer](./ObfuscatorServer.mdx) | Server-side deobfuscation/obfuscation counterpart. | Paired with `ObfuscatorClient`. |
| [PacketCounter](./PacketCounter.mdx) | Receives packet traffic for source-IP discovery in restricted environments. | Packet/IP discovery chains. |
| [PacketGenerator](./PacketGenerator.mdx) | Sends packet traffic for source-IP discovery or packet-path tests. | Packet/IP discovery chains. |
| [PacketSplitStream](./PacketSplitStream.mdx) | Splits one worker packet line into named upload and return branches. | Specialized packet-line helper using `settings.up` and `settings.down`. |
| [PacketsToConnection](./PacketsToConnection.mdx) | Converts packet traffic through lwIP into normal WaterWall connection lines. | Packet-to-connection bridge. |
| [PacketsToStream](./PacketsToStream.mdx) | Carries raw IPv4 packet boundaries over a stream-facing line. | Paired with `StreamToPackets`. |
| [PingClient](./PingClient.mdx) | Carries local IPv4 packets in ICMP Echo Requests, optionally generates exact Echo Replies, and consumes correlated replies as acknowledgements. | Packet chains, paired with `PingServer`; `send-replies` defaults to false. |
| [PingServer](./PingServer.mdx) | Decapsulates peer Echo Requests once, optionally replies exactly, and originates reverse data in new Echo Requests. | Packet chains, paired with `PingClient`; `send-replies` defaults to false. |
| [QuicClient](./QuicClient.mdx) | Carries application bytes in a reliable QUIC v1 stream with TLS 1.3. | Before a separate UDP carrier, or a stream carrier with explicit framing; paired with `QuicServer`. |

| [RawSocket](./RawSocket.mdx) | Sends and receives raw IP packets. | Packet edge. |

| [Router](./Router.mdx) | Routes lines by context, filters, or rule branches. | Middle of complex chains. |

| [Socks5Client](./Socks5Client.mdx) | Speaks to an upstream SOCKS5 server. | Before a transport/proxy destination. |

| [SpeedLimit](./SpeedLimit.mdx) | Applies throughput limiting. | Middle of a chain. |
| [SpeedTestClient](./SpeedTestClient.mdx) | Generates speed-test traffic. | Test chains, paired with `SpeedTestServer`. |
| [SpeedTestServer](./SpeedTestServer.mdx) | Responds to speed-test traffic. | Test chains, paired with `SpeedTestClient`. |
| [StreamFragmenter](./StreamFragmenter.mdx) | Splits selected upstream TCP payloads into ordered fragments with configurable delays. | Middle of a TCP chain at the desired shaping point. |
| [StreamToPackets](./StreamToPackets.mdx) | Reconstructs IPv4 packets from a stream-facing line. | Paired with `PacketsToStream`. |
| [TcpConnector](./TcpConnector.mdx) | Opens outbound TCP connections. | Chain end. |
| [TcpListener](./TcpListener.mdx) | Accepts inbound TCP connections and creates normal lines. | Chain head. |
| [TcpUdpConnector](./TcpUdpConnector.mdx) | Combines TCP and UDP connector behavior behind one node. | Chain end for mixed TCP/UDP routing. |

| [TesterClient](./TesterClient.mdx) | Generates deterministic validation traffic and verifies responses. | Test chain head. |
| [TesterServer](./TesterServer.mdx) | Responds to deterministic tester traffic. | Test chain end. |
| [TlsClient](./TlsClient.mdx) | Performs real client-side TLS and carries encrypted TLS records. | Before `TcpConnector` or another transport. |
| [TlsServer](./TlsServer.mdx) | Performs real server-side TLS termination. | After `TcpListener` and before cleartext protocol nodes. |
| [TrojanClient](./TrojanClient.mdx) | Writes Trojan client request/auth framing. | Paired with `TrojanServer`, usually inside TLS. |
| [TrojanServer](./TrojanServer.mdx) | Parses and authenticates Trojan client traffic. | Paired with `TrojanClient`, usually inside TLS. |
| [TunDevice](./TunDevice.mdx) | Reads and writes packets through an operating-system TUN device. | Packet edge. |
| [UdpConnector](./UdpConnector.mdx) | Sends outbound UDP traffic, with optional destination selection/resolution. | Chain end. |
| [UdpListener](./UdpListener.mdx) | Accepts UDP peers and creates stateful lines per peer. | Chain head. |
| [UdpOverTcpClient](./UdpOverTcpClient.mdx) | Carries UDP-style packets over stream transport. | Paired with `UdpOverTcpServer`. |
| [UdpOverTcpServer](./UdpOverTcpServer.mdx) | Server side of UDP-over-TCP handling. | Paired with `UdpOverTcpClient`. |

| [VlessClient](./VlessClient.mdx) | Writes plain VLESS v0 client request framing. | Paired with `VlessServer`, often inside TLS/Reality transport. |

## Choosing A Starting Chain

- Simple TCP proxy: `TcpListener -> ... -> TcpConnector`
- Stateful UDP proxy: `UdpListener -> ... -> UdpConnector`
- Stateless UDP packet edge: `UdpStatelessSocket -> ...`
- Full IP tunnel: `TunDevice -> ... -> TunDevice`
- WireGuard-style packet transport: `UdpStatelessSocket -> WireGuardDevice -> TunDevice`
- Packet over stream bridge: `PacketsToStream` on one side and `StreamToPackets` on the other
- Rootless connection-to-packet bridge: `TcpListener -> Socks5Server -> ConnectionToPackets -> ...`, with
  `PacketsToConnection -> TcpUdpConnector` on the far side
- Multiplexed stream transport: `MuxClient` on one side and `MuxServer` on the other
- HTTP tunnel over TLS: `HttpClient -> TlsClient -> TcpConnector`, with `TlsServer -> HttpServer` on the server side
- Reality-style visitor/protected split: `RealityClient` toward `RealityServer`, with `RealityServer.settings.destination` pointing to the visitor branch
- VMess over WebSocket/TLS: `VmessClient -> HttpClient -> TlsClient -> TcpConnector`, with `TlsServer -> HttpServer -> VmessServer` on the server side
- QUIC over UDP: `TcpListener -> QuicClient -> UdpConnector`, with `UdpListener -> QuicServer -> TcpConnector` on the server side
- ENet over UDP: `TcpListener -> EnetClient -> UdpConnector`, with `UdpListener -> EnetServer -> TcpConnector` on the server side
- GNS over UDP: `TcpListener -> GnsClient -> UdpConnector`, with `UdpListener -> GnsServer -> TcpConnector` on the server side
