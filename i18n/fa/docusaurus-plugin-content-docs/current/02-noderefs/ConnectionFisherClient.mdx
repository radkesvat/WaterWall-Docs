# ConnectionFisherClient

`ConnectionFisherClient` سمت client برای `ConnectionFisherServer` است. این نود
برای هر line ورودی چند child line همزمان به سمت `next` می‌سازد، روی هرکدام probe
پنج‌بایتی `FISH?` می‌فرستد و اولین child line را که پاسخ معتبر `FISH!` بگیرد
نگه می‌دارد.

## کاربرد رایج

وقتی مسیر خروجی ناپایدار است یا می‌خواهید چند تلاش همزمان انجام شود و اولین
مسیر سالم انتخاب شود، از این نود استفاده می‌شود.

```text
TcpListener -> ConnectionFisherClient -> TcpConnector
TcpListener -> ConnectionFisherServer -> TcpConnector
```

## نمونه تنظیم

```json
{
  "name": "fisher-client",
  "type": "ConnectionFisherClient",
  "settings": {
    "simultaneous-tries-perline": 3
  },
  "next": "tcp-out"
}
```

## فیلدهای لازم

| فیلد | نوع | توضیح |
| --- | --- | --- |
| `name` | string | نام node در config. |
| `type` | string | باید `"ConnectionFisherClient"` باشد. |
| `next` | string | نود بعدی که child lineها به سمت آن ساخته می‌شوند. |

این نود باید هم نود قبلی داشته باشد و هم `next`. chain head یا chain end نیست.

## تنظیمات

| گزینه | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `simultaneous-tries-perline` | integer >= 1 | `2` | تعداد child lineهایی که برای هر line اصلی ساخته می‌شود. |

## رفتار مهم

- probe سمت client برابر `FISH?` است.
- پاسخ سمت server برابر `FISH!` است.
- line اصلی مستقیم به `next` فرستاده نمی‌شود؛ فقط child lineها به سمت `next`
  می‌روند.
- payload تا زمان انتخاب winner در صف نگه داشته می‌شود.
- اگر هیچ child line معتبری تا `5000 ms` انتخاب نشود، line اصلی بسته می‌شود.
- اگر payload صف‌شده قبل از انتخاب از `1 MiB` بیشتر شود، line اصلی بسته می‌شود.
- اگر child line پاسخ نامعتبر بگیرد یا handshake buffer آن از `4096 bytes`
  بیشتر شود، مسیر fail می‌شود.
- بعد از انتخاب winner، child lineهای اضافه بسته می‌شوند و payloadهای صف‌شده
  به ترتیب روی winner ارسال می‌شوند.

## نکته‌ها

- این نود باید با `ConnectionFisherServer` استفاده شود.
- برای chainهای stream طراحی شده است، نه packet-line.
- probe ثابت است و مکانیزم امنیتی محسوب نمی‌شود.
- `required_padding_left` آن `0` است.
- upstream `Est` و downstream `Init` برای این نود غیرفعال هستند.
