# ConnectionFisherServer

`ConnectionFisherServer` سمت server برای `ConnectionFisherClient` است. این نود
ابتدا منتظر probe پنج‌بایتی `FISH?` می‌ماند، در صورت معتبر بودن پاسخ `FISH!`
را به سمت client می‌فرستد و سپس line را وارد حالت forwarding معمولی می‌کند.

## جایگاه رایج

```text
TcpListener -> ConnectionFisherServer -> TcpConnector
```

این نود را فقط در مسیری قرار دهید که قرار است از `ConnectionFisherClient` ترافیک
بگیرد.

## نمونه تنظیم

```json
{
  "name": "fisher-server",
  "type": "ConnectionFisherServer",
  "next": "service"
}
```

در نسخه فعلی `settings` اختصاصی ندارد.

## فیلدهای لازم

| فیلد | نوع | توضیح |
| --- | --- | --- |
| `name` | string | نام node در config. |
| `type` | string | باید `"ConnectionFisherServer"` باشد. |
| `next` | string | نود بعدی که payload بعد از probe به آن ارسال می‌شود. |

این نود باید هم نود قبلی داشته باشد و هم `next`. chain head یا chain end نیست.

## رفتار probe

| جهت | مقدار | توضیح |
| --- | --- | --- |
| client به server | `FISH?` | پنج بایت اول upstream باید دقیقاً همین مقدار باشد. |
| server به client | `FISH!` | بعد از probe معتبر ارسال می‌شود. |

## رفتار مرحله‌ای

- upstream `Init` فقط state داخلی را آماده می‌کند و بلافاصله به `next` عبور
  نمی‌کند.
- تا زمانی که حداقل پنج بایت دریافت نشود، upstream payload در buffer نگه داشته
  می‌شود.
- اگر پنج بایت اول `FISH?` نباشد، line بسته می‌شود.
- بعد از probe معتبر، `FISH!` به downstream ارسال می‌شود.
- اگر بعد از probe معتبر payload اضافه وجود داشته باشد، `next` init می‌شود و آن
  payload ارسال می‌شود.
- اگر payload اضافه وجود نداشته باشد، init کردن `next` تا رسیدن payload بعدی
  عقب می‌افتد.
- بعد از established شدن، payload و pause/resume/est به صورت عادی forward
  می‌شوند.

## محدودیت‌ها

| محدودیت | مقدار |
| --- | --- |
| طول probe | `5 bytes` |
| حداکثر handshake buffer | `4096 bytes` |
| `required_padding_left` | `0` |

## نکته‌ها

- این نود باید با `ConnectionFisherClient` استفاده شود.
- برای chainهای stream طراحی شده است، نه packet-line.
- probe ثابت است و مکانیزم امنیتی محسوب نمی‌شود.
- upstream `Est` و downstream `Init` برای این نود غیرفعال هستند.
