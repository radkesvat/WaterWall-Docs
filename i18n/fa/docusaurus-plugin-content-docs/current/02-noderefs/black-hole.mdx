# BlackHole

`BlackHole` یک تونل sink برای مصرف کردن payload است. این نود payload را عبور
نمی‌دهد، اما بسته به `mode` می‌تواند lifecycle زنجیر را زنده نگه دارد یا همان
ابتدای رسیدن upstream init اتصال را ببندد.

## کاربردهای رایج

- تست اینکه بخش‌های دیگر زنجیر در برابر نبود payload چه رفتاری دارند.
- ساخت policy ساده برای drop کردن ترافیک بدون تغییر نودهای دیگر.
- مصرف payload در سناریوهای benchmark یا debug.

## نمونه تنظیم

حالت passive:

```json
{
  "name": "dropper",
  "type": "BlackHole",
  "settings": {
    "mode": "passive"
  },
  "next": "next-node"
}
```

حالت active:

```json
{
  "name": "rejector",
  "type": "BlackHole",
  "settings": {
    "mode": "active"
  }
}
```

## تنظیمات

| گزینه | نوع | توضیح |
| --- | --- | --- |
| `mode` | string | حالت کار نود. این مقدار اجباری است و مقدار پیش‌فرض ندارد. |

## حالت‌ها

حالت `passive` اتصال را از نظر lifecycle نگه می‌دارد و فقط payload دو طرف را
drop می‌کند. نام‌های هم‌معنی آن شامل `drop`، `packet-drop`، `silent` و `calm`
هستند.

در حالت `passive`، callbackهای lifecycle در مسیر upstream به نود بعدی forward
می‌شوند، البته اگر `next` وجود داشته باشد. callbackهای downstream نیز به نود
قبلی forward می‌شوند. payload در هر دو جهت recycle و drop می‌شود.

حالت `active` برای بستن سریع اتصال است. نام‌های هم‌معنی آن شامل `close`،
`aggressive`، `kill` و `kill-connection` هستند.

در پیاده‌سازی فعلی، حالت `active` هنگام upstream `Init` بلافاصله
`tunnelPrevDownStreamFinish()` را به سمت نود قبلی می‌فرستد و همان‌جا برمی‌گردد.
این حالت upstream `Init` را به `next` forward نمی‌کند.

## رفتار payload

| جهت | رفتار |
| --- | --- |
| upstream payload | با `lineReuseBuffer(line, buf)` recycle و drop می‌شود. |
| downstream payload | با `lineReuseBuffer(line, buf)` recycle و drop می‌شود. |

این نود payload را frame، prepend، encrypt، decode یا rewrite نمی‌کند و
`required_padding_left` آن `0` است.

## نکته‌ها

- این نود adapter شبکه نیست؛ socket باز نمی‌کند و به آدرس remote وصل نمی‌شود.
- برای ساخت زنجیری که باید پاسخ application تولید کند مناسب نیست، چون payload
  هیچ‌وقت از آن عبور نمی‌کند.
- `packet-drop` فقط alias حالت passive است و نود را به packet tunnel تبدیل
  نمی‌کند.
- این نود تنظیمات protocol، credential، port یا framing ندارد.
